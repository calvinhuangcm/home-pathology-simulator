# 壁癌模擬器

保留原有三欄 UI、Three.js 場景、工具幾何、孔位清單與滑鼠／觸控流程，Scenario 01「外牆裂縫滲水」、02A「浴室防水層失效」、02B「熱水暗管破損」共用獨立的 TypeScript 分層網格引擎。

介面提供繁體中文、English、日本語三種語言，可從頁首切換；語言偏好會保存在目前瀏覽器。模擬狀態、情境與量測結果不會因切換語言而重置。工程名詞與教學說明依各語言翻譯，情境模型與數值維持同一套規則。

## 啟動

在 Finder 雙擊專案根目錄的 `啟動壁癌模擬器.command`，即可啟動本機伺服器並自動開啟瀏覽器。終端機會保持開啟以顯示訊息；按 Ctrl+C 停止伺服器。若模擬器已在執行，啟動檔會直接開啟現有頁面。

也可以手動執行：

```sh
./scripts/run.sh dev
```

開啟 http://127.0.0.1:5173/。腳本優先使用已安裝的 Node 與 pnpm/npm；此電腦沒有系統 Node 時，會使用 Codex 已提供的本機 runtime。

一般 Node 環境也可以執行 `npm install`、`npm run dev`。專案使用 Vite 7，Node 版本需符合 [Vite 的需求](https://vite.dev/guide/)。目前 pnpm lockfile 固定已驗證的依賴版本。

`壁癌模擬器.html` 現在是模組版入口導向頁。模組版需要本機 HTTP server；若要直接開啟原本單檔版本，使用 [原版備份](docs/original-prototype.html)。原始檔完整保存在該備份中。

## 操作 Scenario 01

1. 初始牆體為 8% 基線；保留降雨，切換 **20×**。大約 1–3 分鐘模擬時間後，室內下方會逐漸形成濕區。
2. 選「檢測」，在同材質的乾牆記錄基準，再點濕區。移動探頭顯示即時數值與 NORMAL / WARNING / HIGH / VERY HIGH。固定樣本保留量測時刻的數值。
3. 沿表面裂縫選「鑽孔」。鑽孔需要 2 秒模擬時間，會顯示進度與粉塵；暫停時也會停止。
4. 選「塞針」，點孔位或使用作業按鈕固定針頭，再選「注入」。本階段只開放真正實作的 PU。
5. 壓力逐漸建立，材料沿連通裂縫移動、遇水膨脹，最多注入 180 ml。錯誤孔位只在孔附近留料，不會封住遠處水源。
6. 選「驗證」，在相同雨勢／側風下觀察 120 秒模擬時間。入水先降低，殘留水分會持續移動並逐漸乾燥；已形成的白華、黴菌與漆面損傷保留。

正常模式只顯示表面，孔位不直接公布是否命中。剖面可選六個材質層。**DEBUG** 提供 Moisture Heatmap、Water Flow、Crack Network、Injection Material、Leak Source。源頭標記只在 DEBUG 的 Leak Source 圖層顯示。

仍保留原來的拖曳旋轉、滾輪／雙指縮放、正面定位、全景、量測記錄、孔位清單、暫停、重置、撤銷與鍵盤快捷鍵。物理操作撤銷會恢復該操作之前的完整引擎快照（包含模擬時間）。

## 語言切換

使用頂端的語言選單切換繁體中文、English 或日本語。初次使用預設繁體中文；選擇會存在瀏覽器的 `localStorage`，下次開啟時沿用。語言只影響介面文字，不會改變模擬時間、材料狀態、操作紀錄或情境進度。

## 操作 Scenario 02A：浴室防水層失效

1. 選 **02A 浴室防水失效**，切到 **20×**，保留「淋浴／地坪用水」。觀察約 180 秒模擬時間。
2. 左側「浴室 · 供水與源頭修繕」可切換 **相鄰房間的浴室外側牆腳**、**樓下房間的天花底面**。兩個位置共用樓板—牆腳水路，但不是同一房間；各自量測同表面的乾區與濕區。
3. 試按「只清理／重塗目前室內濕損表面」。2 秒作業結束只清除該表面的損傷，不清除牆內水；持續供水會再受潮、再析鹽。
4. 關閉「淋浴／地坪用水」→「重作浴室防水與牆地交界」。15 秒教學作業完成後，重新開啟地坪用水。
5. 選 **驗證** → **開始 120 秒驗證**。比較相同供水下的樓板入滲通量與表面濕度。殘留水分慢慢下降，已形成的白華與漆損要另行整修。
6. DEBUG 的「Leak Source」可看面狀供水；選「防水層」與「裂縫／防水缺損」可查看破口。正常模式隱藏內部來源。

## 操作 Scenario 02B：老舊熱水暗管破損

1. 選 **02B 熱水暗管破損**，以 **20×** 觀察約 120 秒。水從牆內破管沿槽路下移，再在較低牆腳析出。
2. 關閉淋浴仍有管內壓力，漏水會持續；改變供水壓力會改變入水通量。室內表面重塗無法修好破管。
3. 關閉 **熱水供水閥** → **隔離舊暗管 → 接通新明管**。10 秒教學作業完成後，正常視圖可看到新明管；舊管留在牆內但已隔離。
4. 重新開閥，恢復原供水壓力，再執行 **120 秒驗證**。新管有壓力、舊管無壓力、原漏水通量為 0；牆體水分仍需時間下降。

Scenario 02 的鑽孔、PU 按鈕停用，使用已實作的源頭修繕工具。淋浴停止／關閥並不等於修復，驗證會要求恢復供水，且不能改低壓力冒充減漏成效。作業可暫停、撤銷、重置。新明管的水溫、熱傳、接頭施工與實際水力設計尚未模擬。

## 操作排水管、多重漏水與地下室

- **排水管漏水**：先關閉一般排水，再選一支管做 20 秒有限測試。測試只開啟選定支管，依來源通量計算結果，到時由模擬時間自動停水；之後可獨立修復並在相同排水事件下確認隔離效果。
- **多重漏水**：浴室防水層失效與排水管破損同時供水。分別停用及修復；只處理一個來源時，另一個來源仍會漏。
- **地下室負水壓**：調整相對地下水位，水壓由水位和入口高度推導。迎水側防水修復需先解除示範水壓；室內側封堵可在水壓持續時示範，但只限制向室內傳輸，不會關閉地下水來源。
- **診斷證據與評分**：含水量測、熱像、供水事件與修繕會依模擬時間寫入證據軸。可對多個來源提出假設並設定信心，再提交來源準確率、涵蓋率與信心校準分數。評分是教學回饋，不是現場判定。
- **熱像判讀**：可調室內／室外溫度、相對濕度、日照強度與時間、表面放射率和反射環境溫度。畫面顯示簡化表面溫度估算、露點、判讀信心及溫差／日照／反射警示，並註明非實測值。

## 操作室內地板

1. 在左側「室內地板 · 表面與含水」選 **室內地板俯視**。地板為地磚／填縫、砂漿找平層、RC 三層；可拖曳旋轉與縮放。
2. 使用原水分儀在地板上量測。非針式讀取表層，針式讀取砂漿；每個位置的讀值來自 floor.cells。
3. 選 **定點淋水測試 · 5 秒**，再點地板位置。供水只持續 5 秒模擬時間，之後自動結束；Pause 凍結供水、擴散和乾燥。
4. 在濕區和遠處乾區建立同儀器對照；切到針式比較下方砂漿。填縫連通區的水分較容易進入砂漿，地磚表面較慢。
5. DEBUG 的 Moisture Heatmap／Water Flow 可以分別觀察三層；Leak Source 的粉紅框是進行中的淋水位置，灰框是已完成的測試紀錄。
6. 完成後持續觀察乾燥，或撤銷淋水操作；重置、切換情境會清除地板測試與儲水。點牆、拖曳及雙指縮放不會誤放地板水源。

Scenario 01／02A／02B 的地板已與相鄰牆腳連接。02A 這塊地板屬同樓層相鄰房間，和浴室上方樓板／樓下天花分開。其餘四個情境的地板也有獨立含水模型與定點測試，但原牆面水路尚未接入，介面會說明。

地板含水值與牆／天花含水值分開顯示；局部地板淋水不會把乾牆的讀值改成地板最高值。來源修繕驗證需先等淋水供水結束，以免同時改變測試條件。

目前採簡化磁磚地坪，尚無坡度、自由積水流動、落水口排水或木地板；時間、傳輸率與施水單位為教學尺度。

## 驗證指令

```sh
./scripts/run.sh lint
./scripts/run.sh typecheck
./scripts/run.sh test
./scripts/run.sh build
# 先在另一個終端維持 dev server；瀏覽器測試預設使用已安裝的 Google Chrome
./scripts/run.sh test:browser
# 只驗證三語切換、狀態不重置與語言偏好保存
./scripts/run.sh test:browser:i18n
# 只跑 Scenario 02
./scripts/run.sh test:browser:bathroom
# 只跑地板量測、淋水、乾燥與觸控
./scripts/run.sh test:browser:floor
# 只跑排水、多重漏水、地下室、診斷與熱像流程
./scripts/run.sh test:browser:diagnostic
```

瀏覽器測試只透過 UI 操作，開發限定 `?test=1` 提供狀態快照與 3D 座標投影，沒有寫入物理狀態的測試捷徑。截圖與報告存於 `artifacts/`。

## 實作範圍

- Scenario 01：六層材質、42 × 24 × 6 個 cell、固定 0.05 秒 timestep、水分擴散、裂縫傳輸、蒸散乾燥、累積損傷、真實 cell 量測、鑽孔／塞針／PU／驗證流程。
- Scenario 02A：樓板與牆體共 12096 個 cell，面狀供水、可破損防水層、牆地交界交換、雙表面量測、源頭防水修復。
- Scenario 02B：帶壓暗管、位移濕區、供水閥／壓力、舊管隔離、明管恢復供水。兩案都有表面整修復發與同條件驗證。
- 排水、多重漏水、地下室：有限單支排水測試、支管獨立隔離與修復、面狀浴室漏水併發情境、地下水位推導水壓、正／負水壓側修復差異。
- 診斷／熱像：模擬時間證據軸、多來源假設與信心計分；熱像環境條件、估算溫度、露點、判讀警示與教學信心。
- 室內地板：80 × 28 × 3，共 6720 個 cell；材質與表層模型、填縫吸水、三層擴散、牆腳交換、蒸散、有限淋水與實際地板探頭。
- 窗框、管線陷阱、結露與樓頂仍未移植網格物理；卡片不標「舊版示意」，副標題會說明引擎接合狀態。
- UI 語系：繁體中文、英文、日文；模擬引擎與診斷狀態不依語言分叉。
